返済試算 Ver2.36.1（起動画面・中心光粒子版）

GitHub Pagesへの反映方法
1. このZIPを展開します。
2. 中のファイルをリポジトリ直下へ上書きアップロードします。
3. 既存のPWAをホーム画面に追加済みの場合は、GitHub反映後に一度アプリを閉じて開き直してください。表示が残る場合は、ホーム画面のショートカットを削除してChromeから再追加してください。

今回の変更
- 起動画面を、下から湧き上がる高密度の細かな粒子演出へ変更
- 流入から円運動へは、同じ粒子の座標を段階的にブレンドして自然に移行
- ローディングバーのような先頭光は廃止し、粒子群が大まかに円運動する表現へ変更
- 1つだけ明るい粒子が下から上がり、円の中心で控えめに2回瞬く
- 終了時は回転を保ったまま粒子数が徐々に減ってフェードアウト
- 主粒子は1080粒、描画は最大30fps、端末のDPRは最大2に制限
- ダークホーム背景の余韻粒子を236粒へ増量（約18fps相当）
- PWAキャッシュ名を更新し、旧起動画面のキャッシュが残りにくいよう調整

既存データについて
- 直近履歴・保存条件・テーマ設定は既存のローカル保存領域をそのまま使うため、保持されます。


【今回の調整】
・試算結果を主返済額中心のレイアウトに整理
・PDF印刷用に青系ヘッダーとカード背景を追加
・PDFで色を出す場合は、印刷設定の「背景のグラフィック」を有効にしてください。
