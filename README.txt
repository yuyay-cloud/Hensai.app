返済試算 Ver2.36.2 UIパッチ

今回のZIPは「現在GitHubに上がっているVer2.36.1のindex.htmlを上書きしない」更新です。

GitHubのルートに、このZIP内の4ファイルをアップロード（上書き）してください。
  - sw.js
  - manifest.json
  - v2362-ui.css
  - v2362-ui.js

index.html はそのまま残してください。

反映手順
1. 4ファイルをGitHubのindex.htmlと同じ階層へアップロード。
2. GitHub PagesのURLをChromeで1回更新。
3. タブを閉じてもう一度開く。
4. ホーム画面アプリを使っている場合は、旧アプリを終了して開き直す。

サービスワーカーが現行のindex.htmlへUIパッチを自動で読み込む構成です。
初回だけ古い画面が出る場合は、再読み込み後に反映されます。

内容
- 比較画面をA/Bの項目横並びサマリーへ再構成
- 比較詳細を1本の高密度比較表へ変更（返済額/元金/利息/残高を切替）
- 通常の返済予定表をスマホでも大きなカードではなくコンパクト表へ変更
- 返済日の和暦/西暦切替を追加
- 結果サマリーにPDFと統一した円弧・光点モチーフを追加
- ダーク/ライト両方で背景の粒子と流れの余韻を強化
